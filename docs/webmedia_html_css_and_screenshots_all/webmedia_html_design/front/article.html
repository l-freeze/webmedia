最初に必要な機能

1人運営のWEBメディアでは、記事作成、公開管理、画像管理、SEO設定、問い合わせ管理が中心になります。装飾よりも、迷わず使えることを優先します。

記事管理の基本

  • 下書き保存
  • 公開・非公開
  • 公開予約
  • 更新履歴と復元
公開事故を防ぐには、公開前プレビューと予約状態の明示が重要です。

公開予約と履歴管理

公開日と公開時刻を指定できるUI、過去バージョンへ戻せる履歴画面を用意します。
