# WEBメディア HTML/CSS デザイン一式

## 内容

- `front/`: ユーザーフロント HTML/CSS
- `cms/`: CMS HTML/CSS
- `screenshots/front_pc/`: ユーザーフロント PC版キャプチャ
- `screenshots/front_sp/`: ユーザーフロント モバイル版キャプチャ
- `screenshots/cms_pc/`: CMS PC版キャプチャ
- `screenshots/cms_sp/`: CMS モバイル版キャプチャ

## キャプチャ対象

### ユーザーフロント

トップ、記事詳細、カテゴリ一覧、カテゴリ詳細、タグ一覧、タグ詳細、検索結果、検索結果なし、問い合わせ、問い合わせエラー、問い合わせ完了、運営者情報、プライバシーポリシー、404、ローディング、記事なし、スマホメニュー。

### CMS

ログイン、ダッシュボード、記事一覧、記事編集、プレビュー、更新履歴/バージョン管理、固定ページ管理、カテゴリ/タグ管理、メディア管理、問い合わせ管理、サイト設定、ゴミ箱。

## 備考

- 画像はダミーのグラデーション領域です。
- HTML/CSSは静的モックです。フォーム送信や保存処理は実装していません。
- キャプチャはPC幅・モバイル幅を分けて作成しています。
