- プレビュー

### 今回追加・強化した要件

- 固定ページ管理を専用章として明確化
- 固定ページにもSEO設定、OGP設定、履歴、バージョン管理を追加
- 記事編集画面の「非公開にする」操作を明示
- 記事一覧の「複製」操作を明示
- ゴミ箱に記事だけでなく固定ページも含めることを明示
- カテゴリ/タグのSEO設定をより明確化
- 公開予約解除、非公開確認、復元確認などの状態を明確化

### CMS側の判定

デグレなし。前回の要件を維持し、不足していた固定ページ管理と非公開操作を補強している。
